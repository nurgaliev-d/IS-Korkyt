# Несие / Несие алу

Небольшой учебный прототип системы микрокредитования на React и Django.

## Что уже работает

- калькулятор суммы и срока займа;
- форма заявки с проверкой полей;
- сохранение заявок в SQLite через Django API;
- простой раздел менеджера для просмотра и изменения статуса;
- переключение русского и казахского языка.

## Запуск backend

```bash
cd backend
python3 -m pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py test
python3 manage.py runserver 8000
```

## Запуск frontend

В отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

В проекте намеренно нет настоящей авторизации менеджера — это версия первой
недели. Перед публикацией нужны аккаунты, права доступа, журнал изменений,
ограничение запросов и секреты окружения.
