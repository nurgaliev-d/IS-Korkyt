# Бұлттық қауіпсіздік құралдарын салыстыру

| Құрал | Негізгі мақсаты | Артықшылығы | Шектеуі | Осы жобадағы рөлі |
|---|---|---|---|---|
| Trivy | Terraform, контейнер, тәуелділік және құпияларды сканерлеу | Бір құралда бірнеше тексеру түрі бар, CI/CD-ге ыңғайлы | Бұлттағы барлық runtime әрекетін түсіндірмейді | Негізгі IaC және dependency сканері |
| tfsec | Terraform конфигурациясындағы қауіпсіздік қателері | Terraform үшін қарапайым әрі жылдам ережелер | Қазіргі экожүйеде Trivy бағытымен біріктірілуі мүмкін | Қосымша Terraform тексеруі |
| Cloud Custodian | Бұлт ресурстарын policy арқылы аудиттеу және басқару | AWS ресурстарын нақты күйі бойынша тексереді | Орнату және cloud credentials қажет | Public storage және шифрлау аудиті |

## Қорытынды таңдау

Жергілікті зертханалық тексеруге Trivy негізгі құрал ретінде алынады. Terraform-ды `tfsec` арқылы қосымша тексеруге болады. Нақты AWS аккаунтында Cloud Custodian policy-лері ресурстардың runtime күйін бақылайды.

Құралдарды бір-бірінің орнына емес, әртүрлі қабаттарды тексеретін толықтырушы бақылаулар ретінде қолдану керек.
