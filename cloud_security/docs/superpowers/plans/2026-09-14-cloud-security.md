# Бұлттық қауіпсіздік зертханасын іске асыру жоспары

**Мақсат:** Бірінші тапсырмадағы екінші тақырыпқа сәйкес қауіптер матрицасы, қауіпсіз Terraform baseline-ы, аудит policy-лері және қорғауға дайын қазақша презентация құру.

**Архитектура:** Практикалық негізгі модель ретінде AWS таңдалады. Terraform VPC, жеке subnet-тер, шектеулі security group, IAM, KMS, S3 және CloudTrail ресурстарын сипаттайды. Trivy/tfsec IaC конфигурациясын, Cloud Custodian бұлттағы ресурс күйін тексереді.

**Технологиялар:** Terraform, AWS provider, YAML, Markdown, Mermaid, Bash.
