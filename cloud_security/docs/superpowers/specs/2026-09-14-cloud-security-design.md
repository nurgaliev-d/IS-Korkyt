# Бұлттық қауіпсіздік зертханасының техникалық сипаттамасы

## Мақсаты

Бұл жоба бұлттық ортадағы корпоративтік деректерді қорғауға арналған қауіптерді талдауды, қауіпсіз архитектураны және Infrastructure as Code қауіпсіздік baseline-ын көрсетеді.

## Қамту аймағы

- Негізгі практикалық платформа: AWS.
- Салыстыру платформалары: Azure, Yandex Cloud және OpenStack.
- Негізгі деректер: сақтау қоймасы, IAM, желі, шифрлау және аудит журналдары.
- Негізгі құралдар: Terraform, Trivy, tfsec және Cloud Custodian.
- Реалды аккаунтқа қосылу міндетті емес; барлық негізгі тексеру жергілікті орындалады.

## Қауіпсіздік талаптары

1. Интернеттен дерекқорға тікелей кіруге болмайды.
2. Сақтау қоймалары public access арқылы ашылмауы керек.
3. Деректер және аудит журналдары KMS арқылы шифрлануы керек.
4. Әкімшілік әрекеттер MFA арқылы орындалуы керек.
5. Workload рөлі тек қажетті ресурсқа және әрекетке ие болуы керек.
6. CloudTrail және VPC Flow Logs қосылуы керек.
7. Terraform конфигурациясында құпия кілттер сақталмауы керек.
8. Қауіптер, бақылаулар және инцидентке әрекет ету жоспары құжатталуы керек.

## Нәтиже критерийлері

- Қауіптер матрицасы бар.
- Terraform қауіпсіз baseline конфигурациясы бар.
- Cloud Custodian policy-лері бар.
- Автоматты статикалық тексеру скрипті бар.
- UML/C4 және орналастыру диаграммалары README ішінде бар.
- Құралдарды салыстыру және инцидентке әрекет ету жоспары бар.
